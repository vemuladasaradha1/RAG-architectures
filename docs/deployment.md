# Deployment

Keep notebooks as teaching clients and src as the source of truth. A production stack can use FastAPI, Qdrant or FAISS, BM25/OpenSearch, sentence-transformers, an open-weight reranker, and vLLM or llama.cpp. Add logs, tracing, health checks, timeouts, retries, rate limits, evaluation gates, dependency scanning, and container scanning.

Local inference and local databases require no provider API key.
